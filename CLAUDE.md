# Presentation template

Decks in this repo are self-contained HTML files. For any request to make slides or a deck, use the `presentation-slides` skill in `.claude/skills/presentation-slides/`.

- Put each new deck in its own folder at the repo root. Do not edit `demo/` unless asked; it is the reference deck.
- Run `node .claude/skills/presentation-slides/scripts/lint-slides.mjs <folder>` before reporting a deck as done.
- Check each deck in a browser at 1920×1080 and at a non-16:9 size.
